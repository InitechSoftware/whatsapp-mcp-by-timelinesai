# TimelinesAI - WhatsApp Business API for Claude

Connect Claude to your WhatsApp Business API numbers in TimelinesAI. Ask which chats need a reply, then read the history, reply inside the 24-hour window, send an approved template, start a conversation from a template, and label, assign, close or reopen chats.

## What it connects to

The plugin connects Claude to the TimelinesAI WhatsApp Business API server at `https://mcp.services.timelines.ai/mcp/waba`. It works only with WhatsApp Business API numbers connected to your TimelinesAI workspace.

## Setup

1. You need a TimelinesAI account with a WhatsApp Business API number connected. See the [setup guide](https://timelines.ai/whatsapp-business-api-mcp).
2. Install the plugin in Claude Code:

   ```
   /plugin install timelinesai-whatsapp-business --marketplace InitechSoftware/whatsapp-mcp-by-timelinesai
   ```
3. When Claude asks you to connect, sign in with your TimelinesAI account (OAuth). No API key is needed.

Every action runs as you, under your TimelinesAI permissions. Messages are real messages sent to real contacts, so check what Claude is about to send.
